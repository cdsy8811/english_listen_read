# 英语听读软件（Android / uni-app）

把纸质或屏幕上的单词表**拍下来变成词库**，再用三种模式反复听、说、被评价的安卓练习工具。

> **当前状态：P1–P6 工程代码已完成**（2026-11-06）。工程在 [`english-listen-read/`](english-listen-read/)：App / H5 双端编译通过、44 项离线自测全过、类型检查 0 错误、密钥扫描无泄漏。
> **APK 二进制待在 HBuilderX 云打包产出**（本机无 Android SDK，云打包需 DCloud 登录态），步骤见 [`docs/打包指南.md`](docs/打包指南.md)。
> **凭据方案 C：APK 完全独立运行**，装好后不需要电脑、不需要服务器、不需要云账号。第一版 AI、OCR 与语音能力统一使用**讯飞**，App 端直接签名并直连讯飞接口。方案与授权记录见 [`docs/开发方案.md` 第 11 节](docs/开发方案.md)。

## 功能

| 编号 | 功能 |
|---|---|
| 1 | 拍照 → 识别文本 → 筛出单词 / 读音 / 翻译 → 保存到首页（按「学习单元」分组） |
| 2 | 选中已保存内容后，选择要用的练习模式 |
| 2.1 | **中英共读**：朗读中文和英文，按设定间隔自动进入下一条 |
| 2.2 | **看中说英**：读中文，用户录音或输入英文，系统评价（内容正确度） |
| 2.3 | **看英说中**：读英文，用户录音或输入中文，系统评价 |
| 3 | 设置：全局朗读速度；2.1 的间隔时长；2.2 / 2.3 的「提交后进入下一个 / 定时进入下一个」 |

设置项完整矩阵、评分算法和状态机见 [`docs/开发方案.md`](docs/开发方案.md)。

## 技术栈

- **uni-app（Vue3 + Vite + TypeScript）**，App-Plus 打包 Android APK
- 本地 `plus.sqlite`（SQLite）+ 音频缓存，离线可用
- 能力层可插拔：OCR / 结构化抽取 / TTS / ASR / 评测，上层不感知具体实现
- **无后端**：HMAC-SHA256 签名在 App 端完成，`uni.request` / `uni.connectSocket` 直连讯飞；App 端走原生网络栈，不受 CORS 限制
- 第一版云能力：讯飞 Spark X2.6、通用文档识别（OCR大模型 `se75ocrbm`）、语音听写大模型（中英）V2.0、超拟人合成

## 配置与安全（方案 C）

用户已明确：**这是自己学习用的 App**，接受「密钥随 APK 打包、可能被反编译提取」的风险（2026-11-06）。

1. 复制 `.env.example` 为 `.env.local` 填入真实值（真实值见本地 `docs/讯飞接口配置.md`）；构建期注入，**源码仓库里只有键名，没有密钥**。
2. 密钥只存在于**产物 APK** 中：分片存储 / 运行时拼接、代码混淆、打包后做一次免费加固；日志禁止打印 `Authorization`、签名串、完整鉴权 URL 与图片 base64。
3. `docs/讯飞接口配置.md` 与 `.env.local` 已加入 `.gitignore`，请勿 `git add -f`。
4. **讯飞控制台设置用量上限与告警**；APK 只装自己的手机，**不外传、不上架**；发现异常用量立即轮换密钥。
5. 两套凭据互不通用：MaaS 用 `Bearer ak-...`；OCR / 听写 / 合成共用 APPID + APIKey + APISecret 签名。
6. **若要给别人用或上架，必须先迁到云函数方案**（`开发方案.md` 第 11 节 B），不得沿用 C 直接分发。

> 这些密钥曾出现在对话中。若会话会被共享或留存给第三方，建议先轮换再继续开发。

## 第一版边界（已定）与剩余事项

**已定**

- **方案 C 独立运行**：不依赖电脑 / 服务器 / 云账号，装到手机联网即用。
- 2.2 **只做「内容正确度」**，不接 ISE、不给发音分；「2.4」是笔误，只有三种模式。
- P0 联调全绿：MaaS / OCR / 听写 / 合成四个接口鉴权通过，两种 OCR 签名 host 都可用；OCR → Spark X2.6 端到端能产出严格词条 JSON。详见 [`docs/讯飞接口配置.md` 第 8 节](docs/讯飞接口配置.md)。
- 实测 OCR 对 IPA 音标 3/3 损坏，**音标一律由 Spark X2.6 按单词重新生成 + 人工校对**，OCR 音标直接丢弃。

**剩余（都在打包侧，不是代码侧）**

- 在 HBuilderX 登录 DCloud 账号、获取 AppID、云打包产出 APK（见 `docs/打包指南.md` 第 2–3 节）。
- 打包后做一次免费加固并重新签名；在讯飞控制台确认用量上限与告警已设置。
- 真机（Android 10–15）跑一遍：关掉电脑、换网络，拍照入库 + 2.1 共读 + 2.2 / 2.3 作答全流程；断网时首页与已缓存音频可用。
- 英文超拟人发音人 vcn 的授权状态以真机为准，不可用会自动降级安卓原生 TTS。

## 常用命令

```bash
cd english-listen-read
npm install                 # 安装依赖
npm run prepare:env         # 从本地凭据文档生成 .env.local（已 gitignore）
npm run prepare:config      # 生成密钥分片 src/api/generated/credentials.ts（已 gitignore）
npm run verify:secrets      # 打包前必跑：确认仓库无明文密钥
npm test                    # 44 项离线自测
npx vue-tsc --noEmit        # 类型检查
npm run build:app           # 编译 App 资源到 dist/build/app/
```
